## Ветки и worktree

Ветки Codex называются `codex/<задача>` (Git-поток и владение файлами — в
[CLAUDE.md](CLAUDE.md)). Каждая задача выполняется в отдельном `git worktree`;
параллельные исполнители получают отдельные worktree, ветки и явные списки
принадлежащих им файлов.

## Субагенты

Исполнители и субагенты-ревьюеры запускаются как субагенты. Уровень размышления
основной сессии — `medium`, субагентов — `high`: при каждом запуске явно задавай
`reasoning_effort="high"`. Если API допускает этот параметр только без наследования
истории, используй `fork_turns="none"` и передавай задачу, пути, применимые директивы и
критерии приёмки явно. Не меняй модель без поручения пользователя; если нужный уровень
недоступен, сообщи об ограничении и не выдавай запуск с `medium` за `high`.

Обмен заданиями и результатами между субагентами идёт через `collaboration` tools;
отдельного разрешения на каждую передачу не нужно. Отдельные пользовательские чаты
создавай только по явному поручению пользователя. Субагент-ревьюер не участвует в
авторстве, только читает код, diff, требования и результаты проверок и не меняет файлы;
решение о приёмке и правила ревью — по [CLAUDE.md](CLAUDE.md).
